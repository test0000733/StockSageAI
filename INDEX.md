## 🚀 Quick Command Reference

### Validation & Testing
```bash
python validate_deployment.py    # Check setup
python test_training_stack.py    # Run 9 tests
python demo_training_pipeline.py # Run all 8 models
```

### Running Application
```bash
streamlit run StockSageAI/app.py # Start app (localhost:8501)
```

### Docker
```bash
docker-compose up               # Run with Docker
docker-compose down             # Stop Docker
```

### Deployment Check
```bash
python validate_deployment.py   # Pre-deployment check
```
